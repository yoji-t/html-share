Siri × Appleショートカット × Notion MCP

iPhoneから音声でNotionの特許情報を検索・参照する仕組みの構築ガイド

1. 今回実現したいこと

iPhoneのSiriに話しかけるだけで、Notionに保存している特許情報を検索し、 ChatGPTなどのAIで内容を整理・要約して、音声や画面で回答を受け取る仕組みを構築する。

  • Notionの特許データベースを音声で検索する。
  • ミシュランなど特定企業の特許を探す。
  • 特許の技術内容や発明のポイントを要約する。
  • 複数の特許を比較・分析する。
  • 検索結果をiPhoneで読み上げる。

3. Notion MCPの接続方式

今回はNotion公式のRemote MCPを利用する方式を採用する。 独自にNotionの検索機能を一から作る必要はない。

接続先

https://mcp.notion.com/mcp

認証

Notion Developer Portalで発行するMCP Tokenを使用し、 Bearer Tokenとして中継サーバーから送信する。

MCP TokenはNotion MCP専用の認証情報であり、Notion REST API用の APIトークンとは別物。トークンを他人に共有したり、 GitHubの公開リポジトリに登録したりしないこと。

利用条件

  • Notion BusinessまたはEnterpriseプランが対象。
  • Developer PortalでのMCP Token発行にはワークスペースオーナー権限が必要。
  • MCPは接続ユーザーのNotion権限を引き継ぐ。

5. 中継サーバーの機能

初期バージョンは、Notionの情報を検索・取得する読み取り専用構成。

API機能
GET /healthサーバー稼働確認
GET /v1/statusNotion MCPの接続・ツール確認
POST /v1/searchNotion内のページ検索
POST /v1/fetch指定したNotionページの内容取得

セキュリティ対策

  • APIキーによる中継サーバーへのアクセス制限。
  • Notion MCP Tokenを環境変数で管理。
  • HelmetによるHTTPセキュリティヘッダー設定。
  • リクエスト回数制限。
  • 初期版ではページ作成・更新などの書き込み機能を提供しない。

6. 実際の導入手順

STEP 1：Notion MCP Tokenを発行する

  1. Notion Developer Portalにアクセスする。
  2. ワークスペースオーナーとしてログインする。
  3. MCP Tokenの発行画面からトークンを発行する。
  4. 発行したトークンを安全な場所に保管する。

公式ガイド： Notion MCP Getting Started

STEP 2：GitHubにファイルを登録する

  1. GitHubで新しいリポジトリを作成する。
  2. リポジトリはPrivate（非公開）にする。
  3. ZIPを展開する。
  4. 中にあるファイルをリポジトリに登録する。
Notion MCP Tokenや中継APIキーをソースコードに直接書き込まないこと。 .envなどの秘密情報ファイルをGitHubに登録しないこと。

STEP 3：Renderにデプロイする

  1. Renderにアカウントを作成する。
  2. GitHubアカウントを接続する。
  3. 作成したPrivateリポジトリを選択する。
  4. Blueprintを使ってデプロイする。
  5. 環境変数を設定する。

必要な環境変数

変数名内容
NOTION_MCP_TOKENNotionで発行したMCP Token
SHORTCUT_API_KEYショートカット認証用のランダムなAPIキー

Render： https://render.com/

無料プランでは一定時間アクセスがないとスリープする場合がある。 Siriから素早く利用したい場合は、有料プランも検討する。

STEP 4：サーバーの動作確認

Renderから発行されたURLを使って確認する。

https://YOUR-SERVICE.onrender.com/health

次にNotion MCPの接続確認を行う。

https://YOUR-SERVICE.onrender.com/v1/status

さらに検索APIでNotion内のページを検索する。

POST /v1/search

この段階でNotionの検索結果が返れば、中継サーバーの基本動作を確認できる。

STEP 5：iPhoneのショートカットを作成する

Appleの「ショートカット」アプリで新しいショートカットを作成する。

  1. 「テキストを音声入力」：Siriへの質問を受け取る。
  2. 「URL」：Renderの中継サーバーのURLを指定する。
  3. 「URLの内容を取得」：POSTでJSON形式の質問を送信する。
  4. 「辞書の値を取得」：レスポンスの検索結果を取り出す。
  5. 「モデルを使用」：取得した情報をAIに渡して回答を作る。
  6. 「結果を表示」または「テキストを読み上げる」：回答を受け取る。

「モデルを使用」アクションでは、クラウドモデルを選択する構成を想定。 利用できるモデルやアクションはiOSのバージョンや端末設定によって異なる。

9. 今後の拡張案

第1段階：検索・参照

  • Notionの特許ページを音声検索。
  • 指定ページの本文を取得。
  • 特許の要約と発明のポイントを回答。

第2段階：特許分析

  • 企業別の特許出願動向分析。
  • 技術分野別の分類と比較。
  • 複数特許の共通点・相違点の抽出。
  • 研究開発テーマや競合他社の技術動向の分析。

第3段階：Notionへの書き込み

  • 検索結果の要約をNotionに保存。
  • 特許分析レポートを新規ページとして作成。
  • 既存ページに分析結果を追記。

ただし、第3段階は今回の読み取り専用版には含まれていない。 書き込み機能を追加する場合は、Notionの権限、確認操作、 誤更新防止などを別途設計する。
